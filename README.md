# LSA AI & Machine Learning Internship

My weekly practical work for the LSA AI & Machine Learning internship. Each week contains its own notebook, results, setup instructions and README.

## Week 1 — News classification and evaluation

[View the Week 1 project](Week%201/README.md) · [Open the notebook](Week%201/week1.ipynb)

Compare manual labels, two AI prompts and official labels for 30 news items. Explore agreement, Cohen’s kappa, data leakage, class imbalance, confidence intervals and input validation. Includes a Gradio interface and a sentiment and sarcasm label audit using BESSTIE.

The practical experiments are saved. The final write-up and submission evidence are being completed. See the Week 1 README for results, limitations and the submission checklist.

## Working locally

Open the internship folder in VS Code, then select the shared Python environment as the notebook kernel. Follow the setup instructions inside each week’s README and run terminal commands from that week’s folder. The local `.venv` is excluded from Git.
